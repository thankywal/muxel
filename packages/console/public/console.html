Deploy it, step by step

  1. Create a Cloudflare account

    The free plan is enough. Confirm the email it sends you.

  2. Create a GitHub account

    You never write code there. It keeps the copy your deployment updates from.

  3. Think of a console key

    Any phrase, 16 characters or more. It is what signs you in to this console, so keep it to yourself.

  4. Press deploy

    On the form set CONSOLE_KEY to that phrase. Leave the rest alone.

  5. Come back here

    Cloudflare gives you a URL for your deployment. Paste it below, then your key, and the console opens.

  6. Telegram, if you want it

    Optional, and later is fine. /newbot to @BotFather gives you a bot your customers write to; a second one is this console in your pocket, with ADMIN_BOT_TOKEN set to its token and OWNER_TELEGRAM_ID to the number @userinfobot replies with.
